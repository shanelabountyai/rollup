| D-32 | How strict RU-03 is ("may only use numbers present in the result set") | exact string match; **value match at written precision** | a number written with *d* decimals matches a numeric cell within half a unit of its last digit (rounding allowed, inventing not). `$`, thousands separators and `k`/`M`/`B` scales are understood. `%` matches ratio×100 or a value already in percent.
