The SQL that ran

Drafted by the demo's fake model (no API key in this build) 
SELECT channel,
       SUM(spend_usd)                          AS spend_usd,
       SUM(new_customers_first_touch)          AS customers_ft,
       SUM(spend_usd) / NULLIF(SUM(new_customers_first_touch), 0) AS cac_first_touch,
       SUM(spend_usd) / NULLIF(SUM(new_customers_last_touch), 0)  AS cac_last_touch
FROM   mart_channel_quarter
WHERE  quarter = '2026-Q3'
GROUP  BY channel
ORDER  BY cac_first_touch DESC
LIMIT  500
